## はじめに

新潟県の山間部や里山では近年、ツキノワグマの人里への出没が深刻な問題になっています。農作物への被害、登山者や農作業中の住民との遭遇事故、そして「危険動物として駆除」という結末。ニュースになるたびに「また熊か」と受け流してしまいがちですが、少し立ち止まって考えてみてください。

**なぜ熊は、わざわざ人里に下りてくるのでしょうか？**

好奇心や凶暴性から来るものではありません。多くの場合、背景には森の中での**食料不足**、**気候変動による木の実の不作**、そして**人間活動によって変化した山の環境**があります。熊は生きるために、ギリギリの判断を繰り返しています。

---

## なぜこのアプリを作ったのか

「熊の出没問題は深刻だ」と聞いても、ほとんどの人は他人事として捉えます。ニュースを読んでも「怖いね」で終わってしまう。

問題意識はここにあります。**住民が課題を自分事にするには、頭で理解するより先に「感じる」体験が必要ではないか。**

熊の生態を解説するパンフレットや講演も大切です。でも、それだけでは届かない人たちがいます。高校生も、保護者も、地域に関心が薄い世代も。

そこで試みたのが、**「熊の視点に立ってサバイバルを体験する」というアプローチ**です。食料を探し、人間のゴミに誘われ、気候の変化に翻弄されながら冬眠を目指す。その体験を通じて、「熊が悪者」という単純な図式に疑問を持ってもらう——そのきっかけを作りたかった。

---

## どんなアプリか

`bear_hibernation` は、ツキノワグマの視点で晩秋の里山を歩き回り、**冬眠前に十分な栄養を蓄えることを目指すブラウザゲーム**です。

プレイヤーは熊となり、森の中で木の実や川魚を探します。しかし食料は十分ではありません。空腹になれば、人間の畑や生ゴミが漂わせる誘惑的なにおいに引き寄せられます。人里に近づけば駆除のリスクが高まる。自然の食料が豊富なルートを選べば安全だが、今年は不作で…という判断を繰り返しながらゲームが進みます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4531677/ec689cae-0be2-4717-b2c6-419f27c7e299.png)

エンディングは「無事に冬眠できた」「餓死」「駆除」の3種類。**どのルートをたどったかによって、見え方が変わります。**

ゲーム終了後にはアンケートが表示され、「なぜ熊が人里に来るか」「熊と人間が共生するために大切なことは？」といった問いかけに回答できます。ゲームで体験した感覚が、その問いをより身近なものにします。

## 実際に触ってみる

**GitHub:** https://github.com/keith-river/bear_hibernation

※現在は上記リポジトリからHTMLファイルをダウンロードして、ブラウザで開くことで動作します。

**操作は非常にシンプルです:**

1. ページを開いてスタートボタンを押す
2. 方向キーまたは画面タップで熊を操作
3. 食料を集めながら冬眠ゲージを満たす
4. 冬眠成功・失敗いずれかのエンディングへ
5. ゲーム終了後にアンケートに回答(任意)

スマートフォンでもPCでも動作します。5〜10分でプレイできます。

## 触ってみて考えてほしいこと

プレイしながら、いくつかのことを感じてもらえたら嬉しいです。

**「なぜ人里に来るか」が、体でわかる体験**

森の食料が十分あれば、熊はわざわざリスクを冒して人里には来ません。来るのは、来ざるをえない状況があるからです。近年、ブナやナラの木の実の不作が全国的に増えています。その背景には気候変動による気温・降水パターンの変化があることが指摘されています。

**「駆除」という選択の重さ**

ゲーム内で駆除エンディングを迎えたとき、どう感じましたか？現実の熊も、同じような選択の結果として命を落としています。2023年度だけで全国で約6,000頭以上が捕獲・駆除されました。これは記録的な数字です。

**「共生」とは何か**

緩衝地帯の整備、電気柵の設置、ゴミ管理の徹底、農作物の収穫残渣を放置しない——共生のための手段はいくつかあります。しかしそれは、**住民一人ひとりの関心と行動があってはじめて機能します。**

あなたの地域では、熊はどんな存在ですか？遠い山の話でしょうか。それとも、少しだけ身近になってきていますか？

## 技術メモ

HTML5 + JavaScript のみで構成されたSPA（シングルページアプリケーション）です。フレームワークは使わず、Canvas APIで2Dゲームを描画しています。音声はbase64エンコードして埋め込んでおり、外部CDN不要でオフライン環境でも動作します。ゲーム後のフィードバックはローカルサーバー(Node.js/Express)へPOSTし、CSVに記録する仕組みを別途用意しています。

```js
// エンディング分岐の骨格
function endGame(kind) {
  if (kind === 'clear')    showOverlay('🐻💤 冬眠成功', '十分な栄養を蓄えて眠りにつきました。', score);
  if (kind === 'starve')   showOverlay('🥀 餓死',       '食料が見つからず、力尽きてしまいました。', null);
  if (kind === 'culled')   showOverlay('🚨 駆除',       '人里に近づきすぎてしまいました。',         null);
}
```

## 生成AI活用について

このアプリは、筆者が**課題設定と設計思想を担い、生成AIと対話しながら実装**しました。

「熊の生態をゲームで表現する」「エンディングに3種類の分岐を設ける」「アンケートをゲーム体験の直後に配置する」——こうした判断はすべて筆者が行っています。生成AIは、その設計をコードに落とす作業を大幅に加速してくれました。

プロンプトでの試行錯誤、動作確認とフィードバックの繰り返し、細部のバグ修正。一人の開発者が数週間かけてやる作業を、対話的なレビューを通じて短期間で形にできました。最終的な動作確認とコンテンツの責任は筆者にあります。

「生成AIが作った」ではなく、「生成AIと作った」という感覚が近いです。

## おわりに

熊と人間の問題は、どちらが悪いという話ではありません。同じ山と里山を共有しながら、生きようとしている存在同士の、ギリギリの接触です。

気候変動が進むほど、山の食料環境は不安定になります。人の手が入らなくなった里山が増えるほど、緩衝地帯は消えます。これは新潟だけでなく、全国の中山間地域が直面しつつある問題です。

**あなたの地域では、自然と人間の境界線はどこにありますか？**

プレイしながら、少しだけ考えてもらえたら嬉しいです。
